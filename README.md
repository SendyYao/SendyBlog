## 📌 What is this repository?

This repository contains **only the generated static files** of the blog.

The files are produced by running:

```bash
hexo generate
```
and the output (public/ folder) is pushed here and deployed via GitHub Pages.

👉 This is NOT the Hexo source repository.

📁 Repository Content
Typical structure of this repository:

```txt
.
├── index.html
├── css/
├── js/
├── images/
├── archives/
└── ...
```

These files are ready-to-serve static assets.

🌍 Live Website
The blog is available at:

👉 https://hexo.yaohub.com/

🚀 Deployment Workflow
Write posts and edit content in the Hexo source repository

Run hexo generate

Commit and push the generated files to this repository

GitHub Actions deploys the site to GitHub Pages

⚠️ Important Notes

❌ Do not edit content directly in this repository

❌ No Hexo configuration or theme files are stored here

✅ All changes should be made in the source repository

This repository exists only for deployment purposes.
