五一长假其一

今天是2026年5月1日，昨天晚上基本上也算作是通宵了。5点多看到抖音大刀哥的关羽直播，可能是五一或王者新出的哪吒联动皮肤，局内地图挺漂亮的，有哪吒电影中的宫殿等元素，我经受不住诱惑，再次安装上游戏，打了几把游戏，加上金牌和加星卡，还是一直连胜，一下子从王者一星干到8星了。早上7点半左右洗漱下楼，刚一到楼下客厅妈妈和牛牛已经把馅饼买回来了。还给我特地买了一个肉馅饼🥙 早餐就是肉饼，花生白米粥和一碗豆浆，吃的很撑。

吃完早餐不可避免的发困。我又要调整作息了，忍住不睡。抽一支烟喝喝咖啡。继续打起了游戏。玩到中午12点多，早上吃的挺撑，加上忙着打游戏就没有下去吃饭。然后就是依旧同步一下DayOne日记到Hexo Blog，发现每次hexo generate，在开启html_minifier后都会全量生成文章静态html，产生git diff，导致public 仓库越来越大。我询问ChatGPT找解决方法，得到上传整个hexo目录到私有github仓库，利用github actions在远程hexo generate并push构建产物到公共仓库上的解决方案。之后又倦了，在隔壁房间躺上一会儿，一不小心睡到晚上9点多。奶奶和牛牛已经要睡觉了。

下楼拿半个早上吃剩的韭菜粉丝饼吃。开始了晚间的工作，首先就是继续测试daytona sandbox，利用daytona cli解决了之前卡住的端口暴露的问题并得到preview url。之后利用daytona python sdk package上传iTab.jar这个SpringBoot服务jar包到沙箱中，配置runtime，成功运行，但是实际访问预览URL会有一个警告页面，还有涉及到外部网络访问都需要更高的订阅计划，这就意味着我之前计划免费在serverless上部署iTab和Score服务的计划泡汤了。在此之后就是解决HexoBlog public git仓库越来越大的问题，首先是上传hexo源码到新建的私有仓库HexoSource，忙活了大半个晚上。构建并publish到SendyBlog仓库，最后结果就是SendyBlog仓库commit message丑，尽管同步了源码仓库commit message，但后面会有一个原始提交commit hash url。还有会覆盖移除SendyBlog workflow action，导致只能使用默认的github page从branch构建部署。自定义hexo- calendar-generator效果失效等问题。

又是一个通宵！
