今日小记-2026-07-06

早上刚过8点，就被楼下大厅或门口的妇女交谈和笑声吵醒。闭上眼睛想继续睡下去，但又是一阵尿急，索性起床去上个厕所，刷个牙洗脸，下楼了。

虽然时间才是刚8点半多，但是妈妈已经吃过早饭工作了，我看到大桌子上有一大碗盛起来的疙瘩头，里面有一个水煮荷包蛋，蛋花飘散着，蛋黄都染黄了整碗汤，有点腥，没什么胃口了。但我又不得不吃，烧一锅清水，把干的疙瘩头挑出来重新加热，加点盐和南德调味料和黄豆酱就吃下去。

早餐没有肉，虽然调味比较鲜，但依旧改变口感的寡淡，高碳水的早餐，让我觉得一整天都将脑袋昏沉沉的。

吃完早餐，上楼看着电脑网页版的抖音，应该是《名侦探柯南》重制高清版第28集《毛利小五郎同学会杀人事件》，抽一支普皖。在两间房间走过来走过去，坐在床上继续看iPad抖音。时间来到上午10点50左右，没过一会儿，困意如期而至，我躺在床上，iPad放在手边，闭上眼睛，飘飘然睡过去。醒来已经是中午12点多，有点口干舌燥，狂灌两口水，杯子里水见底了，下楼倒水喝。妈妈已经吃完午饭，桌子上有西红柿炒鸡蛋、酸辣土豆丝（老抽可能放多了，有点黑），和瓠子，不怎么饿，刚睡醒没什么胃口，倒杯水就上楼了，不知怎么搞得又睡过去。

这样一觉就睡到下午3点多了，窗外大道上有卖包子馒头的叫卖声。醒来到后门阳台走上一圈，听到楼下妈妈揉面的声音，我也就下楼，和妈妈说晚上不想吃面，早上才吃的疙瘩头，一天到晚都是吃面了，碳水爆表。口干舌燥，给妈妈说我想吃西瓜，昨晚外出听到西瓜才8毛一斤。她以忙，没时间外出拒绝，说等到她有时间才去买。我在楼下客厅桌子上趴着，有点累，乘乘凉。

之后上楼看看Salt Player开发者的iOS版开发进度，没取得什么信息，倒是偶然看到XMuisc应用，有iOS版，还支持音源导入，我顺着Github仓库地址找，但是原作者仓库已经404了，倒是其前身LX Music还有仓库，我就在Google搜索XMusic IPA，找到一个下载链接，不过是关注微信公众号获取的，网站应该是基于Alist部署开发的，有disable-devtools反爬反调试，但难不倒我用chrome more tools开启开发者工具，想断点调试看网络请求，谁曾想一刷新就自动关闭标签页，还是反爬策略，最后我直接删除页面Pop窗口元素（用于输入从公众号获取的访问码），底下的下载链接就显现了，真是得来全不费功夫。顺利获取到XMusic.ipa,下一步应该是自签安装的iPad或iPhone，但是我不想再用Sideloadly了，之前开发测试SendyDynamic时自签每7天过期都要重新连接电脑来安装，有点麻烦。尝试使用AltStore和SideStore，然后又是安装iCloud，又是"The server return invalid response"的。

下午5点30左右下楼吃晚饭，是手擀面，调料就是黄豆酱，配有中午的土豆丝，虽然晚上妈妈又在隔壁买了几个卤鸡爪，但我一个都不吃。

吃完晚饭，老老实实用Sideloadly安装，成功安装XMusic,然后就是导入音源，顺利搜索播放包括QQMusic、酷我、酷狗、咪咕等全平台音乐。之后就是戴着耳机，听着音乐，来到后门阳台抽一支烟。

抽完烟，回到房间，写着昨天和今日的DayOne记录。

That’s it.
